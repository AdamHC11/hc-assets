# hc-assets

Public static assets for HollywoodChicago.com, served via jsDelivr.

- `email/` — fixed images used in HC emails (header logo band, marquee, Hookup winner stamp).
- `posters/` — email-sized copies of per-item images (e.g. Decided pick posters) for HTML copied out of the email builder.

URL pattern: `https://cdn.jsdelivr.net/gh/AdamHC11/hc-assets@<commit-sha>/email/<file>`

Public by design — never put private content here.
